# セカンドハウス管理アプリ

共同で借りている部屋を管理するためのWebアプリです。スマホのホーム画面に追加すると、普通のアプリのように使えます。

## できること

| 画面 | 内容 |
|---|---|
| 📅 予約 | 泊まる日（夜）と泊数で登録します。例：20日の夜〜21日の朝なら「20日・1泊」。カレンダーには泊まる日の真ん中から翌朝の日の真ん中までバーで表示します |
| 💴 精算 | 家賃・駐車場・光熱費・その他の4項目で、1人ずつの金額を計算します。支払い済みにすると、チェックした日時と人が残ります |
| 💬 掲示板 | 鍵の場所やWi-Fi、ゴミ出しのルールなどを共有します。大事な投稿は一番上に固定できます |
| ⚙️ 設定 | メンバーの追加、家賃・駐車場の金額、いつもの支払い者、PIN・合言葉の変更 |

**ログインの流れ**：最初に合言葉を入れ、自分の名前をタップして **4桁のPIN** を入れます。2回目からはどちらも不要です（利用者を切り替えるときは、もう一度PINを入れます）。

### 割り勘のルール

| 項目 | 金額 | 割り方 |
|---|---|---|
| 家賃 | 毎月固定（設定画面で決める） | 選んだ人で均等に割る |
| 駐車場 | 毎月固定（設定画面で決める） | 選んだ人で均等に割る |
| 光熱費 | 毎月入力 | 選んだ人の中で、**その月に泊まった夜の数に比例**して割る（予約カレンダーから自動計算。誰も泊まっていない月は均等割り） |
| その他 | 毎月入力（内容のメモ付き） | 選んだ人で均等に割る |

「割る人」は項目ごとに選べます（例：駐車場は車を使う人だけ）。次の月は前の月の選び方を引き継ぎます。
1円未満は切り捨て、端数は支払い者（まとめて払う人）の負担になります。

**使う仕組み**
- データの保存とログイン：**Firebase**（Google）。無料で、しばらく使わなくても止まりません。
- 公開：**GitHub Pages**。無料で、GitHub に push すると自動で更新されます。

## セットアップ手順（初回のみ・20〜30分）

### 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインします。
2. **プロジェクトを作成** を押し、好きな名前（例：`second-house`）を入れます。
   Google アナリティクスは **オフ** で大丈夫です。

### 2. 合言葉（共有アカウント）を作る

1. 左メニューの **構築 → Authentication → 始める** を押します。
2. **ログイン方法（Sign-in method）** タブで **メール / パスワード** を選んで **有効** にし、保存します。
3. **ユーザー** タブで **ユーザーを追加** を押し、次のように入力します。
   - メール：`house@example.com`（このままでOK。メールは送られません）
   - パスワード：**メンバーで共有する合言葉**（6文字以上）
4. （おすすめ）**設定** タブ →「ユーザー アクション」で **「作成（登録）を有効にする」のチェックを外し**、保存します。
   ※ 外し忘れても、データは下のルールで守られます。

### 3. データベースを作る

1. 左メニューの **構築 → Firestore Database → データベースの作成** を押します。
2. ロケーションは **asia-northeast1（東京）** を選びます。**本番環境モード** で作成します。
3. 作成後、**ルール** タブを開き、このリポジトリの `firestore.rules` の中身を全部貼り付けて **公開** を押します。

### 4. アプリに Firebase の情報を設定する

1. 左上の **⚙（歯車）→ プロジェクトの設定** を開きます。
2. 下の「マイアプリ」で **`</>`（ウェブ）** アイコンを押し、ニックネーム（例：`web`）を入れて **アプリを登録** を押します。
   「Firebase Hosting も設定する」には **チェック不要** です。
3. 表示された `const firebaseConfig = { ... }` の中身（`apiKey` から `appId` まで）を、`js/config.js` の同じ場所に貼り付けてコミットします。

> `apiKey` は公開しても問題ない値です。データは「合言葉ログイン」と「セキュリティルール」で守られています。

### 5. インターネットに公開する（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → General** の一番下「Danger Zone」で **Change visibility → Public** にします。
   （無料プランの GitHub Pages は公開リポジトリでのみ使えます。設定値の `apiKey` は公開されても問題ありません。）
2. **Settings → Pages** を開き、次のように設定して **Save** を押します。
   - Source：**Deploy from a branch**
   - Branch：**`claude/amazing-euler-01b8of`**、フォルダは **`/ (root)`**
3. 1〜2分待つと、同じ画面に URL が表示されます。
   **https://naoyuki51bld-cell.github.io/haitu/** をメンバーに共有してください。

以降は、このブランチに push するたびに自動で更新されます。

### 6. スマホのホーム画面に追加する

- **iPhone**：Safari で URL を開く → 共有ボタン → **ホーム画面に追加**
- **Android**：Chrome で URL を開く → メニュー → **ホーム画面に追加**

### 7. 使いはじめる

1. 合言葉でログインします。
2. 「メンバーを追加」で全員の名前を登録します（1人がまとめて登録すればOKです）。
3. 自分の名前をタップし、自分専用の **4桁のPIN** を決めます（各メンバーが自分のスマホで行います）。
4. **設定** で「家賃」「駐車場」の毎月の金額と「いつもの支払い者」を入れます。

## よくある質問

**Q. お金はかかりますか？**
かかりません。Firebase の無料プラン（Spark）は、1日あたり読み込み5万回・書き込み2万回まで使えます。数人で使う程度なら、まず届きません。クレジットカードの登録も不要です。

**Q. PINを忘れた**
他のメンバーに 設定 → メンバー →（自分の名前）→「PINをリセットする」を押してもらってください。次に名前を選んだときに、新しいPINを決め直せます。

**Q. PINはどのくらい安全？**
メンバー同士の「なりすまし防止」のためのものです。PINそのものは保存せず、暗号化（ハッシュ化）した値だけを保存しています。外部の人からは、合言葉とセキュリティルールで守られています。

**Q. メンバーが抜けたら？**
設定 → メンバー → その人の「現在のメンバー」のチェックを外します。過去の予約や投稿は残ります。

**Q. 合言葉を変えたい**
アプリの 設定 →「合言葉の変更」から変えられます。「一度ログアウトして入り直してください」と出たら、その通りにしてからもう一度変更してください。
Firebase コンソールの Authentication → ユーザー からも変更できます。

**Q. 共有アカウントのメールアドレスを変えたい**
`js/config.js` の `SHARED_EMAIL` と、`firestore.rules` の中の `house@example.com` を両方書き換え、ルールを公開し直してください。

**Q. ログインすると「権限がありません」と出る**
手順3のルールが公開されているか、ルールの中のメールアドレスが手順2で作ったユーザーと同じかを確認してください。

## ファイル構成

```
index.html             画面の土台
css/style.css          デザイン
js/config.js           ★ Firebase の接続情報（ここだけ書き換える）
js/db.js               Firebase とのやりとり
js/main.js             ログイン・画面切り替え
js/calendar.js         予約カレンダー
js/money.js            精算
js/board.js            掲示板
js/settings.js         設定
firestore.rules        セキュリティルール（Firebase コンソールに貼り付ける）
```

ビルドは不要です。手元で動作確認するときは、このフォルダで `python3 -m http.server` を実行し、http://localhost:8000 を開いてください。
